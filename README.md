# Student Performance & Risk Analyzer (AI Model)

## Overview
This project applies Machine Learning algorithms to analyze student academic indicators (mathematics scores, physics scores, and study hours) to predict potential academic performance and identify risk factors early.

## Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Scikit-Learn

## How It Works
1. Data processing and feature extraction.
2. Supervised learning classification using Random Forest Classifier.
3. Model validation and prediction generation for new test cases.
